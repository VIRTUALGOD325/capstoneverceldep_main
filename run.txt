# DocInsight - Run Guide

This guide covers the fastest ways to run DocInsight. Pick one option.

## Option 1: Docker Compose (all services)
Prereqs: Docker + Docker Compose
```bash
# From project root
docker-compose up --build -d
# Check status
docker-compose ps
# Stop everything
docker-compose down
```

## Option 2: Local Spring microservices (Maven, no Docker)
Prereqs: Java 17 + Maven
```bash
chmod +x scripts/run_all_services.sh
scripts/run_all_services.sh start     # start Eureka, gateway, and all services
scripts/run_all_services.sh status    # show status
scripts/run_all_services.sh logs api-gateway   # tail logs for a service
scripts/run_all_services.sh stop      # stop all
```
Optional:
```bash
export EUREKA_SERVER_URL=http://localhost:8761/eureka
```

## Option 3: Standalone Streamlit UI (optional)
```bash
bash run_docinsight.sh
```
UI: http://localhost:8501

## Troubleshooting (quick)
- Port conflicts: ensure listed ports are free or update configs.
- Health checks: wait for /actuator/health = UP before using a service.
- Docker issues: restart Docker Desktop, then re-run Option 1.
